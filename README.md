# Muhammad Ripaldi — Portfolio

A professional portfolio built with Next.js App Router, Tailwind CSS, Framer Motion, Lucide, and Simple Icons.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Customize

- Replace the Unsplash placeholders in the hero and project cards with your own images.
- Add `Muhammad-Ripaldi-CV.pdf` to `public/` or update the CV links.
- Update the contact email in the header, hero, and footer.

## Checks

```bash
npm run lint
npm run build
```
